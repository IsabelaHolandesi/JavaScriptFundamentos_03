# JavaScriptFundamentos03

Continuação dos estudos de JavaScript com foco em funções, métodos de array, objetos, JSON e introdução à Programação Orientada a Objetos.

## Objetivos

Ao final deste projeto, o aluno deverá ser capaz de:

- Criar e utilizar funções;
- Trabalhar com parâmetros, argumentos e retornos;
- Utilizar Arrow Functions;
- Criar e manipular objetos;
- Trabalhar com array de obejtos;
